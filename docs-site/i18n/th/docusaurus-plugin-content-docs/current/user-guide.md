# Log Dashboard — คู่มือการใช้งาน

**พัฒนาโดย ธนพล อึ้งสกุล (นักศึกษาฝึกงาน Server Operation)**  
ระบบจัดการ Log ของ Docker Container และตัววิเคราะห์ Nginx Access Log แบบ Real-time

---

## ภาพรวม
Log Dashboard เป็นศูนย์รวม Log จาก Docker containers และ Nginx reverse proxies ทั้งหมดไว้ในหน้าเว็บเดียว รองรับการดูแบบ Live stream, การค้นหาย้อนหลัง, กราฟวิเคราะห์ข้อมูล และการกำหนดสิทธิ์ตามบทบาทผู้ใช้

---

## รูปแบบหน้าจอหลัก
หลังล็อกอิน หน้าจอจะแบ่งเป็น 2 ส่วนหลัก:

| ส่วน | คำอธิบาย |
|------|-------------|
| **แถบข้าง (ซ้าย)** | ข้อมูลผู้ใช้, ระดับสิทธิ์ (Badge), รายชื่อ Stack/Container, การตั้งค่า Admin |
| **พื้นที่หลัก (ขวา)** | แถบ Tab ด้านบน และเนื้อหาข้อมูลด้านล่าง |

### แถบ Tab

| Tab | ใครเห็นได้บ้าง | คำอธิบาย |
|-----|---------------|-------------|
| 📄 **Logs** | ทุกคน | หน้าดู Log ของแต่ละ container |
| 📊 **Analytics** | ทุกคน | กราฟสถิติราย container |
| 🛡 **Admin** | Admin, Super Admin | จัดการผู้ใช้ และตั้งค่าระบบ **(เฉพาะ Admin)** |
| 🌐 **Nginx** | Admin, Super Admin | ดู Log และวิเคราะห์ข้อมูล Nginx **(เฉพาะ Admin)** |

---

## แถบด้านข้าง — Stacks & Containers
แถบด้านข้างจะแสดงรายชื่อ **stacks** (กลุ่มของ Docker containers) แต่ละ stack สามารถคลิกเพื่อย่อหรือขยายได้

- **จุดสี** หน้าชื่อ container บอกสถานะการทำงาน:
  - 🟢 **สีเขียว** — มี log ภายใน 60 วินาทีล่าสุด (กำลังทำงาน)
  - 🟠 **สีส้ม** — มี log ภายใน 5 นาทีล่าสุด (เพิ่งทำงาน)
  - ⚪ **สีเทา** — ไม่มี log ล่าสุด (หยุดทำงานหรือไม่มีความเคลื่อนไหว)

คลิกที่ชื่อ container เพื่อโหลด log ในหน้าหลัก

คลิกปุ่ม **+** (บนสุดของแถบข้าง) เพื่อสร้าง stack ใหม่ (เฉพาะ Admin / Super Admin)

## แท็บ Logs

### การดู Log
เลือก container จากแถบข้าง Log จะแสดงในตารางที่มีคอลัมน์ดังนี้:

| คอลัมน์ | คำอธิบาย |
|--------|-------------|
| **Timestamp** | วันที่และเวลาของ log |
| **Level** | ระดับความรุนแรง — ERROR, WARN, INFO, DEBUG |
| **Message** | ข้อความ log ทั้งหมด |
| **Container** | ชื่อ container ต้นทาง |

แถวจะแยกสีตามระดับ: แดง (ERROR), ส้ม (WARN), ฟ้า (INFO), เทา (DEBUG)

### การกรอง (Filtering)
ใช้แถบด้านบนตารางเพื่อกรองข้อมูล:

- **Search** — ค้นหาข้อความใน log
- **Level** — เลือกเฉพาะระดับที่ต้องการ (Error / Warn / Info / Debug)
- **Date From / To** — เลือกช่วงวันที่และเวลาโดยใช้ปฏิทินและเมนูเลือกชั่วโมง/นาที
- **Apply** — เริ่มการกรอง
- **Reset** — ล้างค่าการกรองทั้งหมดและกลับสู่ค่าเริ่มต้น

### Live Stream
คลิกปุ่ม **↻ Live** เพื่อเปิดการดู log แบบ Real-time ข้อความใหม่จะเด้งขึ้นด้านบนสุดของตารางทันที คลิกอีกครั้งเพื่อหยุด

### การส่งออก (Export)
คลิก **Export** เพื่อดาวน์โหลด log ที่ถูกกรองอยู่เป็นไฟล์ JSV การส่งออกจะยึดตามตัวกรองที่คุณตั้งไว้ (container, level, ช่วงเวลา)

## แท็บ Analytics
แสดงสถิติราย container ตามช่วงเวลาที่เลือก:

- **ปริมาณ Log ตามเวลา** — กราฟเส้นแสดงจำนวน log ต่อนาที/ชั่วโมง
- **สัดส่วนระดับ Log** — กราฟวงกลมหรือแท่งแสดงสัดส่วน ERROR / WARN / INFO / DEBUG
- **อัตรา Error** — เปอร์เซ็นต์ของ Error เมื่อเทียบกับทั้งหมด
- **ข้อความ Error ยอดฮิต** — ข้อความ Error ที่พบบ่อยที่สุด

ใช้ตัวเลือก **ช่วงเวลา** ด้านบนเพื่อสลับดูข้อมูล ย้อนหลัง 1 ชม., 24 ชม., 7 วัน หรือเลือกเอง

---

## แท็บ Nginx *(เฉพาะ Admin / Super Admin)*
แบ่งเป็น 2 ส่วน: **Analytics** (ภาพรวมและกราฟ) และ **Logs** (ตารางค้นหาละเอียด)

### ส่วน Analytics
มีเมนูเลือกช่วงเวลาด้านบนซึ่งจะคุมข้อมูลทั้งหมด:
ล่าสุด 5 นาที, 30 นาที, 1 ชม., 6 ชม., 24 ชม. (ค่าเริ่มต้น), 2 วัน, 7 วัน

**การ์ดข้อมูล:**
- **Total Requests** — จำนวนคำขอทั้งหมดในช่วงเวลานั้น
- **Error Rate (5xx)** — อัตราการตอบกลับที่ผิดพลาดจากฝั่ง server (5xx)
- **Total Bytes** — จำนวนข้อมูลทั้งหมดที่ส่งให้ client

**กราฟ Traffic** — กราฟพื้นที่แสดงจำนวน request แยกตามรหัส HTTP status (2xx, 3xx, 4xx, 5xx)
**Top Client IPs** — รายชื่อ IP ที่ขอข้อมูลมากที่สุด
**Top Paths** — URL ที่ถูกเรียกบ่อยที่สุด พร้อมสถิติ error แยกตามเว็บไซต์ (virtual host)

### ส่วน Logs
ตารางแสดง Nginx access log แบบละเอียด ค้นหาได้ทุกฟิลด์

**คอลัมน์:** Client IP, Timestamp, Method, Website, Path, Status, Bytes, Time (เวลาประมวลผล)

**ตัวเลือกการกรอง:**
- **Search path** — ค้นหาตาม URL path
- **Status code** — กรองตามรหัสสถานะ (200, 404, 500, …)
- **Method** — กรองตาม HTTP method (GET, POST, …)
- **Sort** — เรียงตามล่าสุด หรือเก่าสุด
- **From / To** — เลือกช่วงวันที่และเวลา

คลิก **Apply** เพื่อเริ่มกรอง, **Reset** เพื่อล้างค่า, **↻ Refresh** เพื่อโหลดข้อมูลใหม่
**Pagination** — ใช้ปุ่ม **← Prev** และ **Next →** เพื่อเปลี่ยนหน้า (หน้าละ 50 รายการ)

## แท็บ Admin *(เฉพาะ Admin / Super Admin)*

### การจัดการผู้ใช้
ดูรายชื่อผู้ใช้ทั้งหมด พร้อมคอลัมน์: ชื่อผู้ใช้, บทบาท, วันที่สร้าง

- **สร้างผู้ใช้** — เพิ่มบัญชีใหม่ด้วย username, password และบทบาท
- **ลบผู้ใช้** — ลบบัญชีที่ไม่ใช่ SSO (เฉพาะ Super Admin)
- **เปลี่ยนบทบาท** — ปรับระดับสิทธิ์ผู้ใช้ (เฉพาะ Super Admin)

### การตั้งค่า (Settings)
Admin จะเห็นส่วน ⚙️ Settings ด้านล่างแถบข้าง:

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| Log Retention (days) | ระยะเวลาที่เก็บ log ไว้ก่อนลบอัตโนมัติ (ปกติ 90 วัน) |
| Active threshold (sec) | วินาทีสุดท้ายที่ได้รับ log เพื่อแสดงจุดสีเขียว (ปกติ 60) |
| Recent threshold (sec) | วินาทีสุดท้ายที่ได้รับ log เพื่อแสดงจุดสีส้ม (ปกติ 300) |
| Active Color | เลือกสีสำหรับจุดสถานะ active (สีเขียว) |

กด **Save** ข้างแต่ละรายการเพื่อบันทึกทันที

## บทบาทผู้ใช้

| บทบาท | สี Badge | ความสามารถ |
|------|------------|--------------|
| **Developer** | Indigo | ดูแท็บ Logs, Analytics |
| **Admin** | Red | ทุกอย่างข้างต้น + แท็บ Nginx, แท็บ Admin, จัดการผู้ใช้ |
| **Super Admin** | Purple | ทุกอย่างข้างต้น + ลบผู้ใช้, เปลี่ยนระดับสิทธิ์, รัน SQL ตรง |

ระดับสิทธิ์ของคุณจะแสดงอยู่ข้างชื่อผู้ใช้บนแถบด้านข้าง

## การแจ้งเตือน
ไอคอนกระดิ่ง 🔔 มุมขวาบนจะแสดงการแจ้งเตือนระบบ:

- **แจ้งเตือน Error วิกฤต** — เมื่อมี Error เกินขีดจำกัดที่ตั้งไว้
- **แจ้งเตือน Spam** — เมื่อ container มี log เด้งผิดปกติภายใน 1 นาที
- **แจ้งเตือน Container หยุดทำงาน** — เมื่อ container ที่เคยทำงานอยู่หยุดส่ง log เกิน 1 ชม.

คลิกที่กระดิ่งเพื่อเปิดเมนู Unread alerts จะถูกไฮไลท์ไว้ คลิกที่การแจ้งเตือนเพื่อลบทิ้ง

## การแก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---------|-------------|-----|
| ตาราง Log ว่างหลังเลือก container | ไม่มี Log ในช่วงเวลาที่เลือก | ขยายช่วงเวลาดูใหม่ หรือเช็คว่า container ยังรันอยู่ไหม |
| ขึ้น "Unauthorized" ในแท็บ Nginx | สิทธิ์ไม่เพียงพอ | ติดต่อ Super Admin เพื่อขอสิทธิ์ Admin |
| Live stream หยุดนิ่งไม่ขยับ | การเชื่อมต่อ SSE หลุด | ปิดปุ่ม Live แล้วเปิดใหม่อีกครั้ง |
| ล็อกอินแล้วเด้งกลับหน้าเดิม | Session หมดอายุ | ทำการล็อกอินใหม่อีกครั้ง |
| กราฟ Nginx ขึ้นค่า — | Nginx ไม่ส่ง Log ไปยัง ClickHouse | ตรวจสอบระบบ Vector/Fluent Bit บน server |
