# Archive

Reviewed reference material lives here. It is not part of the active runtime stack.

## Rules

- Do not delete first.
- Archive old internship material only after confirming no compose, test, or deploy path depends on it.
- Keep useful evidence, old configs, and reports discoverable instead of leaving them scattered at the repository root.

## Current Areas

```text
archive/internship/     internship-era experiments and old collectors
archive/legacy/         old monitoring/docs-site experiments
archive/reference/      reference files such as FileBeat.zip and old migrations
archive/local/          ignored machine-local notes and artifacts
```
