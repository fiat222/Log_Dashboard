# Log Dashboard — คู่มือการใช้งาน

ระบบดู Log ของ Docker Container และวิเคราะห์ Nginx Access Log แบบ Real-time สำหรับ PSU EILA

---

## เข้าสู่ระบบ

เปิด `/logstore/login` แล้วล็อกอินด้วยบัญชี PSU SSO หรือบัญชีท้องถิ่นที่ Admin สร้างให้

Session จะยังอยู่โดยอัตโนมัติ หากต้องการออกจากระบบ ให้คลิก **Sign Out** ที่แถบด้านข้าง

---

## บทบาทของคุณ

บทบาทกำหนดว่าคุณเห็นแท็บและข้อมูลอะไรได้บ้าง แสดงเป็น Badge สีข้างชื่อผู้ใช้ในแถบด้านข้าง

| บทบาท | สี Badge | สิ่งที่เข้าถึงได้ |
|--------|----------|-----------------|
| **Developer** | Indigo | Logs, Analytics, Patterns — เฉพาะ container ที่ได้รับมอบหมาย |
| **Admin** | Red | ทุกอย่างข้างต้น + แท็บ Nginx, แท็บ Admin, ทุก container |
| **Super Admin** | Purple | ทุกอย่างข้างต้น + ลบผู้ใช้, เปลี่ยนบทบาท |

หากต้องการเปลี่ยนบทบาท ติดต่อ Super Admin

---

## หน้าจอหลัก

หลังล็อกอิน หน้าจอแบ่งเป็น 2 ส่วน:

- **แถบด้านข้าง (ซ้าย)** — ชื่อและบทบาทของคุณ, รายชื่อ container, การตั้งค่า Admin
- **พื้นที่หลัก (ขวา)** — แถบ Tab ด้านบน, เนื้อหาด้านล่าง

### ภาพรวมแท็บ

| Tab | ใครเห็นได้ | หน้าที่ |
|-----|-----------|---------|
| **Logs** | ทุกคน | ดูและค้นหา log ของ container |
| **Analytics** | ทุกคน | กราฟและสถิติราย container |
| **Patterns** | ทุกคน | จัดกลุ่มข้อความ log ที่ซ้ำกันเพื่อดูแนวโน้ม |
| **Nginx** | Admin+ | วิเคราะห์ Traffic และค้นหา Nginx Access Log |
| **Admin** | Admin+ | จัดการผู้ใช้และตั้งค่าระบบ |

---

## แถบด้านข้าง — Containers

แถบด้านข้างแสดงรายชื่อ container ที่จัดกลุ่มเป็น **stacks** คลิกชื่อ stack เพื่อย่อหรือขยาย

จุดสีหน้าชื่อ container บอกสถานะ:

| จุดสี | ความหมาย |
|-------|----------|
| 🟢 เขียว | Active — มี log ภายใน 60 วินาทีล่าสุด |
| 🟠 ส้ม | Recent — มี log ภายใน 5 นาทีล่าสุด |
| ⚪ เทา | ไม่มีความเคลื่อนไหว หรือหยุดทำงาน |

คลิกชื่อ container เพื่อโหลด log ขึ้นมาแสดง

:::note บัญชี Developer
จะเห็นเฉพาะ container ที่ได้รับมอบหมายให้เท่านั้น
:::

Admin สามารถสร้าง stack ใหม่ได้โดยคลิก **+** ที่ด้านบนของแถบด้านข้าง

## แท็บ Logs

### อ่านตาราง Log

| คอลัมน์ | คำอธิบาย |
|--------|----------|
| Timestamp | วันที่และเวลาของ log |
| Level | ERROR · WARN · INFO · DEBUG |
| Message | ข้อความ log ทั้งหมด |
| Container | ชื่อ container ต้นทาง |

สีของแถวบอกระดับ: แดง (ERROR), ส้ม (WARN), ฟ้า (INFO), เทา (DEBUG)

คลิกที่แถวเพื่อดูข้อความเต็ม

### การกรอง

| ตัวควบคุม | หน้าที่ |
|----------|---------|
| ช่องค้นหา | ค้นหาข้อความใน log |
| Level | แสดงเฉพาะระดับที่เลือก |
| From / To | ช่วงวันที่และเวลา (เลือกวันและ HH/MM) |
| **Apply** | เริ่มกรองข้อมูล |
| **Reset** | ล้างค่าการกรองทั้งหมด |

กด `Enter` ในช่องค้นหาเพื่อกรองได้เลยโดยไม่ต้องคลิก Apply

### Live Stream

คลิก **↻ Live** เพื่อดู log แบบ Real-time log ใหม่จะขึ้นด้านบนสุดทันที คลิกอีกครั้งเพื่อหยุด

### Export

คลิก **Export** เพื่อดาวน์โหลด log ที่กรองอยู่เป็นไฟล์ `.jsv` การ Export จะใช้ตัวกรองทั้งหมดที่ตั้งไว้

## แท็บ Analytics

กราฟและสถิติสำหรับ container ที่เลือกในช่วงเวลาที่กำหนด

| Widget | แสดงข้อมูล |
|--------|-----------|
| Log volume over time | จำนวน log ต่อชั่วโมง |
| Level breakdown | สัดส่วน ERROR / WARN / INFO / DEBUG |
| Error rate | เปอร์เซ็นต์ของ Error log |
| Top error messages | ข้อความ Error ที่พบบ่อยที่สุด |

ใช้ตัวเลือก **ช่วงเวลา** ด้านบนขวาเพื่อสลับดูข้อมูลย้อนหลัง 1 ชม., 24 ชม., 7 วัน หรือเลือกเอง

---

## แท็บ Patterns

Patterns จัดกลุ่มข้อความ log ที่คล้ายกันเข้าด้วยกัน ช่วยให้เห็นว่าข้อความไหนเกิดซ้ำบ่อยที่สุด

1. เลือก container ในแถบด้านข้างก่อน (ถ้าต้องการ) เพื่อกรองเฉพาะ container นั้น
2. เลือกช่วงเวลา — **ย้อนหลัง 1 ชั่วโมง** หรือ **ย้อนหลัง 24 ชั่วโมง**
3. คลิก **Load Patterns**

| คอลัมน์ | คำอธิบาย |
|--------|----------|
| Count | จำนวนครั้งที่ pattern นี้ปรากฏ |
| Severity | ระดับ log หลักของ pattern นี้ |
| Pattern | ข้อความที่ normalize แล้ว — `?` แทนส่วนที่เปลี่ยนแปลงได้ |
| First Seen | ครั้งแรกที่พบใน window นี้ |
| Last Seen | ครั้งล่าสุดที่พบ |

คลิกที่แถว pattern เพื่อกระโดดไปแท็บ **Logs** พร้อม pre-fill ค่าค้นหาให้อัตโนมัติ

## แท็บ Nginx *(เฉพาะ Admin+)*

### การ์ดข้อมูลภาพรวม

| การ์ด | แสดงข้อมูล |
|------|-----------|
| Total Requests | จำนวนคำขอ HTTP ทั้งหมดในช่วงเวลานั้น |
| Error Rate (5xx) | เปอร์เซ็นต์ของ error จากฝั่ง server |
| Total Bytes | ข้อมูลรวมที่ส่งให้ client |

ใช้ตัวเลือกเวลาด้านบนเพื่อสลับดูข้อมูล: 5 นาที, 30 นาที, 1 ชม., 6 ชม., 24 ชม., 2 วัน, 7 วัน

### กราฟ

- **Traffic over time** — request ต่อนาที แยกสีตาม HTTP status (2xx / 3xx / 4xx / 5xx)
- **Top Client IPs** — IP ที่ส่ง request มากที่สุด
- **Top Paths** — URL ที่ถูกเรียกบ่อยสุด พร้อมสถิติ error แยกตามเว็บไซต์

### ค้นหา Log

ตารางแสดง Nginx access log แบบละเอียด ค้นหาได้ทุกฟิลด์

**คอลัมน์:** IP · เวลา · Method · Website · Path · Status · Bytes · Response time

**ตัวกรอง:** path · status code · HTTP method · ช่วงวันที่ · การเรียงลำดับ

คลิก **Apply** เพื่อกรอง, **Reset** เพื่อล้างค่า, **↻ Refresh** เพื่อโหลดใหม่ ใช้ **← Prev / Next →** เพื่อเปลี่ยนหน้า (50 รายการต่อหน้า)

## แท็บ Admin *(เฉพาะ Admin+)*

### การจัดการผู้ใช้

ดูรายชื่อบัญชีทั้งหมดในระบบ

| การกระทำ | ใครทำได้ |
|---------|---------|
| สร้างผู้ใช้ท้องถิ่น | Admin, Super Admin |
| เปลี่ยนบทบาท | Super Admin เท่านั้น |
| ลบผู้ใช้ | Super Admin เท่านั้น |

### การตั้งค่า *(ล่างสุดของแถบด้านข้าง)*

| การตั้งค่า | ค่าเริ่มต้น | ผล |
|----------|-----------|-----|
| Log retention | 90 วัน | เก็บ log ไว้นานเท่าไรก่อนลบอัตโนมัติ |
| Active threshold | 60 วินาที | วินาทีที่ไม่มี log ก่อนจุดเปลี่ยนเป็นสีส้ม |
| Recent threshold | 300 วินาที | วินาทีที่ไม่มี log ก่อนจุดเปลี่ยนเป็นสีเทา |
| Dot colors | — | เลือกสีสำหรับจุดสถานะ active / recent |

คลิก **Save** ข้างแต่ละรายการเพื่อบันทึกทันที

## การแจ้งเตือน

ไอคอนกระดิ่ง 🔔 มุมขวาบนแสดงการแจ้งเตือนที่ระบบสร้างอัตโนมัติ

| การแจ้งเตือน | เกิดขึ้นเมื่อ |
|------------|------------|
| Critical log | พบ ERROR-level event ใน log ของ container |
| Log spam | container มี log เพิ่มขึ้นผิดปกติภายใน 1 นาที |
| Container down | container หยุดส่ง log เกิน 5 นาทีและยืนยันว่าหยุดทำงาน |
| Container recovered | container ที่เคยหยุดทำงานกลับมาส่ง log อีกครั้ง |

คลิกที่กระดิ่งเพื่อเปิดรายการแจ้งเตือน คลิก **Mark all read** เพื่อล้าง badge

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|------|--------|
| ตาราง Log ว่างหลังเลือก container | ขยายช่วงเวลา หรือตรวจสอบว่า container ยังรันอยู่ |
| ไม่เห็นแท็บ Nginx | บทบาทเป็น Developer — ติดต่อ Admin เพื่อขอเลื่อนสิทธิ์ |
| Live stream หยุดนิ่ง | ปิด **↻ Live** แล้วเปิดใหม่อีกครั้ง |
| Analytics ไม่มีข้อมูล | เลือก container ในแถบด้านข้างก่อน แล้วเลือกช่วงเวลา |
| Badge กระดิ่งค้างไม่หาย | เปิดรายการแจ้งเตือนแล้วคลิก **Mark all read** |
| Patterns ไม่มีข้อมูล | ลองขยายช่วงเวลา หรือตรวจสอบว่ามี log ของ container อยู่ |
